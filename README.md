# ВАСИЛИСК 2.0 — ИИ-тренер по Dota 2

**Создатель: ALLENAFS**
**При поддержке: Carassius, Репозиторий Гитхабович, GLM**

Василиск смотрит твою игру через официальный интерфейс Valve (Game State Integration) и прямо во время матча
подсказывает голосом и оверлеем, **что покупать, куда идти и что делать**. Никаких серверов и подписок:
всё работает на твоём ПК, а цифры берутся из статистики OpenDota.

| Возможность | Как сделано |
|---|---|
| Советы в реальном времени с озвучкой | GSI-сервер + правила + голос Windows (SAPI) |
| Сборки с таймингами по герою и роли | OpenDota `scenarios/itemTimings` + офлайн-снимок `data/meta.json` |
| Контрпики и винрейты против врагов | OpenDota `heroes/{id}/matchups` |
| «Живой» текст советов и свободные подсказки | локальная нейросеть Ollama (`qwen2.5:7b-instruct`) |
| Файты, ганк, Рошан и Аегис, руны, варды, байбек | правила на данных GSI (счёт убийств, кулдауны, таймеры) |
| Панель в браузере: вопросы ИИ, драфт, роль 1–5 | `http://127.0.0.1:9001/ui` |
| Шанс победы по драфту, контр-предметы | модель на матчах OpenDota (`tools/train_winrate.py`) |
| Разбор матчей после игры | `src/post_match.py` |

## Установка: одна кнопка

**Вариант А (графический).** Двойной клик по `launcher.pyw`, затем **«УСТАНОВИТЬ / ПОЧИНИТЬ ВСЁ»**.
**Вариант Б (консоль).** Двойной клик по `install_all.bat`.

Что делает установщик:

| № | Шаг | Как |
|---|---|---|
| 0 | Python 3.12 (если нет) | winget |
| 1 | Python-пакеты (aiohttp) | `pip install -r requirements.txt` |
| 2 | GSI-конфиг в Dota 2 | копирует в `game\dota\cfg\gamestate_integration\` (все библиотеки Steam) |
| 3 | Параметр запуска `-gamestateintegration` | вписывается в конфиг Steam (при закрытом Steam, с бэкапом `*.vasilisk-bak`) |
| 4 | Ollama + модель `qwen2.5:7b-instruct` (~4,7 ГБ) | winget или установщик с ollama.com, затем `ollama pull` |
| 5 | Снимок меты OpenDota | `tools/fetch_meta.py`, если старше 14 дней |
| 6 | Ярлык на рабочем столе | с иконкой василиска |

Слабый ПК? Сними галочку «ставить ИИ-мозг» (или `--no-llm`): тренер будет говорить шаблонными фразами.
Модель поменьше: `ollama pull qwen2.5:3b-instruct` и поправь `llm_model` в `config.json`.

**После установки перезапусти Steam**, затем «ЗАПУСК ТРЕНЕРА». Dota 2 запускай в режиме **«Окно без рамки»**,
иначе оверлей не будет виден поверх игры.

### Ручная установка

1. Python 3.10+ (python.org, «Add to PATH»), затем `python -m pip install -r requirements.txt`.
2. Скопируй `install/gamestate_integration_vasilisk.cfg` в
   `<Steam>\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\`
   (именно в подпапку `gamestate_integration`, не в корень `cfg`).
3. Steam, Dota 2, Свойства, Параметры запуска: `-gamestateintegration`. Перезапусти Steam.
4. По желанию: Ollama и `ollama pull qwen2.5:7b-instruct`.
5. По желанию: `python tools/train_winrate.py --pages 200` (~5 минут) — модель шанса победы по драфту.

### Не приходят пакеты? Проверь по порядку

1. Нажми «УСТАНОВИТЬ / ПОЧИНИТЬ ВСЁ» ещё раз (кнопка идемпотентна).
2. Конфиг лежит в `game\dota\cfg\gamestate_integration\`, порт в cfg равен порту в `config.json`, токен `vasilisk_2026` совпадает.
3. В параметрах запуска Dota 2 стоит `-gamestateintegration`, Steam перезапущен.
4. Тренер запущен: в логе `[GSI] слушаю http://127.0.0.1:9001/`. Если написано «порт занят», тренер уже запущен.
5. `python tools/capture_gsi.py` (вместо тренера, сыграй минуту, Ctrl+C) покажет, какие блоки реально приходят.

### Какие блоки GSI реально приходят

Valve не документирует GSI официально, и обычный клиент игрока может не отдавать часть блоков (`minimap`, `buildings`,
`events`). Тренер сам проверяет это: после ~30 пакетов он пишет в лог и в панель, чего не хватает, например:
`Не приходят: minimap (видимость врагов) — зависящие подсказки отключены`. Тогда подсказки «враг пропал из вижена»
и «упала башня» не срабатывают, а всё остальное (таймеры, экономика, сборки, файты по счёту убийств, ганк, Рошан) работает.
Проверить свой клиент можно заранее через `tools/capture_gsi.py`.

## Что советует Василиск

**Что покупать:** план сборки с целевыми минутами из `itemTimings` («Бабочка к 20-й»), стартовая закупка, ТП-чек, байбек.

**Куда идти и что делать**
- линия по роли, ротации (враг пропал из вижена: «отойди и жди ганк»);
- **файты по счёту убийств:** выиграли 2+ убийства за 30 секунд, значит «враги на респауне, ломайте башню или Рошана»;
  проиграли, значит «отходи к башне и жди сбор»;
- **ганк:** ульта и ресурсы готовы (нужен блок `abilities`, он включён в cfg);
- руны изобилия, силы, **руна мудрости (7:00 и далее каждые 7 минут)**, Торментор, ночь и день, стаки :53 для саппортов;
- Рошан: смерть, окно респавна 8–11 минут; Аегис 5 минут (от подбора, если он у тебя);
- смок, байбек, отступление при критичном ХП, слишком много смертей.

> Аутпосты с патча 7.33 не дают опыт и обзор, а Tome of Knowledge удалён (его заменила руна мудрости),
> поэтому советов про них нет.

**Контрпики:** враг появился в вижене или выбран в панели: его винрейт против твоего героя, контр-предметы
(невидимки, много контроля, магический урон, побеги, несколько керри).

**Экономика:** GPM и ластхиты против перцентилей твоего героя (p20/p50/p80), по ролям 1–5.

## ИИ и честность данных

Всё, что произносит Василиск, берётся из GSI-пакетов твоей игры и статистики OpenDota. Нейросеть:
1. **пересказывает факт правила** живой фразой; числа и герои, которых нет в факте, запрещены, а такая фраза отбрасывается;
2. раз в ~30 секунд даёт **свободный совет** «что делать сейчас» (числа тоже проверяются по данным матча);
3. отвечает на **вопросы в панели**. Эти ответы могут быть неточными: модель не видит позиций и предметов врагов.

Игра не отдаёт игроку позиции врагов, их предметы и состояние вышек. Поэтому «ломайте башню» значит «у врагов только что
погибли герои», а не «я вижу, что башня слабая».

## Панель `http://127.0.0.1:9001/ui`

Статус (Ollama, модель драфта, блоки GSI), журнал советов, вопрос ИИ, выбор роли 1–5, переключатели голоса и ИИ.
Вкладка «Драфт»: выбери вражеских героев, получишь лучшие пики, контр-предметы и шанс победы по обученной модели.
Панель принимает запросы только с `127.0.0.1`/`localhost`.

## Запуск и проверка

1. `launcher.pyw` или ярлык, «ЗАПУСК ТРЕНЕРА» (или `start.bat`). Лог: `vasilisk.log`.
2. Dota 2, любой матч (первый раз: Play, Create Demo Hero). В логе появится `[GSI] пакет получен…`.
3. Без Dota 2: `start_demo.bat` (24 минуты) или `python tools/full_game_sim.py` (полная игра: пик, 36 минут, пост-гейм).
   Симуляторы проверяют только сам тренер, а не то, что реально присылает твой клиент.
4. Автотесты: `python -m unittest discover tests`.

## Настройки (`config.json`)

- `role`: `carry`/`mid`/`offlane`/`pos4`/`support` или цифры `1`–`5`; `rank`: herald … immortal;
- `voice`, `voice_name`, `tts_rate`: озвучка (пустое имя = голос Windows по умолчанию, русский обычно «Microsoft Irina»);
- `llm`, `llm_url`, `llm_model`: Ollama; `free_coach` и `coach_interval`: свободные подсказки ИИ и их период в секундах.

## Данные

- `data/meta.json`: офлайн-снимок OpenDota (предметы, тайминги, бенчмарки, матчапы). Обновление: `python tools/fetch_meta.py`
  (~7 минут, `--resume` докачает после обрыва). Установщик обновляет его сам, если он старше 14 дней.
- Тайминги рун, Рошана и Торментора зависят от патча: правила в `src/rules_data.py`, `src/advisor.py`, `src/extras.py`.
  После новых патчей их стоит сверять.
- Составные предметы и перенос предметов (тайник, курьер) учитываются приблизительно: тайминги сборки могут немного плыть.

## Правовая сторона (важно)

- **GSI — официальный интерфейс Valve**: игра сама отправляет состояние на твой локальный сервер. Память игры не читается,
  в процесс ничего не внедряется, файлы игры не меняются. Это тот же класс ПО, что стрим-оверлеи. Абсолютной гарантии от Valve нет.
- **FACEIT, ESL и турнирные платформы запрещают** сторонние оверлеи и GSI-клиенты в своих матчах. Выключай Василиска там,
  где правила это запрещают.
- Проект независимый: код, названия и данные сторонних коммерческих программ в нём не используются.

## Структура

```
launcher.pyw / install_all.bat   центр управления и установщик «в один клик»
install/                         GSI-конфиг для Dota 2
src/   main.py gsi_server.py state.py advisor.py extras.py builds.py llm.py tts.py overlay.py webui.py winmodel.py post_match.py rules_data.py
tools/ install_all.py simulate_match.py full_game_sim.py capture_gsi.py fetch_meta.py train_winrate.py mock_ollama.py
tests/ автотесты на GSI-пакеты
data/  meta.json (снимок OpenDota)
```

```
Dota 2 --GSI POST--> 127.0.0.1:9001 (gsi_server.py)
   -> state.py (слияние пакетов)  -> advisor.py + extras.py (правила)
   -> llm.py (Ollama: факт -> живая фраза, свободные советы, вопросы)
   -> tts.py (SAPI-голос) + overlay.py (окно советов) + webui.py (панель)
```
