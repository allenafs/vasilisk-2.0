# ВАСИЛИСК 2.0 - ИИ-тренер по Dota 2

**Создатель: ALLENAFS**
**При поддержке: Carassius Репозиторий Гитхабович, GLM**

Василиск смотрит твою игру через официальный интерфейс Valve (Game State Integration) и прямо во время матча подсказывает голосом и оверлеем, **что покупать, куда идти и что делать**. Никаких серверов и подписок: все работает на твоем ПК, а цифры берутся из реальной статистики OpenDota, ничего не выдумывается.

| Возможность | Как сделано |
|---|---|
| Советы в реальном времени с озвучкой | GSI-сервер + правила + голос Windows (SAPI) |
| Сборки с таймингами по герою и роли | OpenDota `scenarios/itemTimings` (живая статистика покупок) + офлайн-снимок |
| Контрпики и вингейты против врагов | OpenDota `heroes/{id}/matchups`: "Снайпер - жесткий матчап: 41% побед" |
| "Живой" текст советов | локальная нейросеть Ollama (qwen2.5:7b-instruct) |
| Миникарта (ганк-тревоги) | частично: "враг пропал из вижена" + совет по вардам |
| Разбор твоих матчей после игры | `src/post_match.py` - перцентили GPM/XPM, тайминги кор-итемов |

## Установка - одна кнопка

**Вариант А (графический, рекомендуется).** Запусти **`launcher.pyw`** двойным кликом и нажми **"УСТАНОВИТЬ / ПОЧИНИТЬ ВСЕ"**. Готово.

**Вариант Б (консольный).** Запусти **`install_all.bat`** двойным кликом.

Одна кнопка сама ставит и чинит все, что нужно для полного функционала:

| № | Что ставит | Как |
|---|---|---|
| 0 | Python 3.12 (если его совсем нет) | winget, молча |
| 1 | Python-пакеты (aiohttp) | pip install -r requirements.txt |
| 2 | GSI-конфиг в Dota 2 | копирует в `game\dota\cfg\gamestate_integration\` (находит Steam во всех библиотеках) |
| 3 | Параметр запуска `-gamestateintegration` | прописывает в конфиг Steam сам (нужен закрытый Steam; иначе даст инструкцию) |
| 4 | Ollama + модель `qwen2.5:7b-instruct` (около 4,7 ГБ) | winget или установщик + `ollama pull` |
| 5 | Свежий снимок меты OpenDota | `tools/fetch_meta.py` (если снимку больше 14 дней) |
| 6 | Ярлык "ВАСИЛИСК 2.0" на рабочем столе | с иконкой василиска, запуск одним кликом |

Слабый ПК или мало места? Сними галочку "ставить ИИ-мозг" (или запусти с `--no-llm`): тренер будет говорить шаблонными фразами, все остальное останется без изменений.

**После установки перезапусти Steam** (чтобы параметр запуска вступил в силу) и жми "ЗАПУСК ТРЕНЕРА".

### Ручная установка (если очень хочется)

1. **Python 3.10+** с python.org (при установке отметь "Add to PATH").
2. `python -m pip install -r requirements.txt`
3. Скопируй `install/gamestate_integration_vasilisk.cfg` в
   `<Steam>\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\` -
   именно в подпапку **`gamestate_integration`**, а не в корень `cfg`.
4. Steam - Библиотека - Dota 2 - правый клик - Свойства - Общие - Параметры запуска:
   ```
   -gamestateintegration
   ```
   Без этого Dota 2 не отправляет GSI-пакеты. После добавления перезапусти Steam.
5. (Желательно) Ollama с ollama.com + `ollama pull qwen2.5:7b-instruct`.

### Не приходят пакеты? Проверь по порядку

1. Нажми "УСТАНОВИТЬ / ПОЧИНИТЬ ВСЕ" еще раз: кнопка проверит все повторно и ничего не сломает.
2. Конфиг лежит в `game\dota\cfg\gamestate_integration\` (не в корне `cfg`), порт в конфиге совпадает с портом из `config.json`, токен `vasilisk_2026` тот же.
3. В параметрах запуска Dota 2 стоит `-gamestateintegration`, Steam перезапущен после добавления.
4. Тренер запущен и слушает (в логе есть строка `[GSI] слушаю http://127.0.0.1:9001/`).
5. Сыграй минуту и посмотри, что реально отправляет твой клиент:
   ```
   python tools/capture_gsi.py
   ```
   Запусти скрипт вместо тренера, поиграй минуту и нажми Ctrl+C: он покажет, какие блоки приходят, и сохранит первый пакет в `gsi_first_payload.json`.

### Честно про minimap и buildings

Советы "враг пропал из вижена" и "их башня пала - пуш" опираются на блоки `minimap` и `buildings`. У большинства клиентов они приходят (та же схема работает у популярных GSI-оверлеев с функцией "missing enemies"), но Valve не документирует GSI официально, и гарантий на каждый патч нет. Поэтому тренер **сам следит за потоком**: если после начала настоящего матча этих блоков нет, он честно напишет об этом в лог и перечислит отключенные функции. Проверить свой клиент заранее можно так: `python tools/capture_gsi.py`.

## Что советует Василиск (каждая цифра - из реальных данных)

**Что покупать**
- план сборки с целевыми минутами из живых `scenarios/itemTimings` ("ПТ к 8-й, Батл фьюри к 17-й" - типичные минуты тысяч матчей);
- стартовая закупка из снимка популярности (`itemPopularity`, 127 героев);
- после закрытия кора - люксы из топ-предметов лейта на этом герое;
- проверка ТП, томики для саппортов, отложенный байбек после 25-й минуты.

**Куда идти**
- старт: линия по роли ("иди на легкую, проси саппорта закрыть лагеря");
- ротации: враг пропал из вижена - "отойди и жди ганк", с зоной, где его видели;
- объекты: аутпосты на 10/20/30 минутах, руны каждые 2/3 минуты, стаки на :53;
- ночь и день: вард на руну с наступлением темноты, обновление леса на рассвете.

**Что делать**
- Рошан: после смерти Рошана окно респавна 8-11 минут, аегис живет около 5 минут - "стягивайся к питу";
- аегис, чиз или гем в кармане - подсказка, как ими распорядиться;
- смок-минуты, байбек после смерти, отступление при критическом ХП, когда рядом враг;
- пуш после падения чужой Т2 и деф своей Т3 (из блока buildings).

**Контрпики (реальные вингейты)**
- враг появился в вижене - Василиск покажет его вингейт против твоего героя из сотен тысяч матчей: "Снайпер - жесткий матчап: 41% побед - играй аккуратнее" или "Против Зевса перевес 67% - дави его".

**Экономика**
- GPM и ластхиты против перцентилей твоего же героя (p20/p50/p80 из OpenDota).

## Данные (почему тренер не выдумывает)

Все, что произносит Василиск, приходит ровно из двух мест:
1. **живое состояние матча** - GSI-пакеты твоего клиента Dota 2;
2. **реальная статистика OpenDota** - живые запросы при старте и офлайн-снимок `data/meta.json` (уже в комплекте, дата внутри файла): популярность предметов по фазам, бенчмарки GPM/XPM/ластхитов, вингейты матчапов и винрейты всех 127 героев.

Нейросеть не придумывает, а пересказывает готовый факт: ей запрещено добавлять героев, предметы и числа, которых в факте нет. Фраза с выдуманными цифрами отбрасывается, и озвучивается исходный шаблон.

Обновить снимок под свежий патч:
```
python tools/fetch_meta.py            # полный снимок, около 7 минут
python tools/fetch_meta.py --resume   # докачать после обрыва
```
Кнопка "УСТАНОВИТЬ / ПОЧИНИТЬ ВСЕ" тоже обновляет снимок, если он старше 14 дней.

## Запуск в бою

1. Запусти **`launcher.pyw`** (или ярлык "ВАСИЛИСК 2.0") и нажми "ЗАПУСК ТРЕНЕРА" (или запусти `start.bat`): появится оверлей и голос. Полный лог - `vasilisk.log`.
2. Запусти Dota 2 и любой матч (в первый раз удобнее демо-герой: Play - Create Demo Hero). При первом пакете в логе появится строка `[GSI] пакет получен...`.
3. Проверка без Dota 2: `start_demo.bat` - симулятор пришлет 24-минутный матч (Рошан, БКБ, ганк Пуджа, падение башни).
4. Полная симуляция одной игры (запуск, пик, матч, пост-гейм):
   ```
   python tools/full_game_sim.py
   ```

## Настройки (config.json)

- `role` - carry / mid / offlane / support / pos4 (влияет на план GPM и вардов);
- `rank` - от herald до immortal (план по GPM и ластхитам);
- `voice` / `voice_name` / `tts_rate` - озвучка (пустое имя - голос Windows по умолчанию; русский голос обычно "Microsoft Irina", смотри Параметры - Время и язык - Речь);
- `llm`, `llm_url`, `llm_model` - локальная нейросеть Ollama.

## Разбор матчей (после игры)

```
python src\post_match.py --steamid 76561198XXXXXXXXX
python src\post_match.py --matchid 3703866531
```
Покажет GPM и XPM против перцентилей твоего брекета, поздние покупки кор-итемов ("БКБ на 28-й, обычно к 24-й"), варды, стаки и выводы. Отчет сохраняется в `post_match_report_*.txt`.

## Правовая сторона (важно)

- **GSI - официальный интерфейс Valve**: игра сама отправляет состояние на твой локальный HTTP-сервер. Это не читерский софт, память игры не читается, VAC за это не банит (так же работают стрим-оверлеи турниров).
- **FACEIT, ESL и турнирные платформы запрещают** любые сторонние оверлеи и GSI-клиенты в своих матчах - выключай Василиска там, где правила это запрещают.

## Как это устроено (коротко)

```
Dota 2 --GSI POST--> 127.0.0.1:9001 (gsi_server.py)
   -> state.py (слияние пакетов: Рошан, предметы, миникарта, башни)
   -> advisor.py (правила-триггеры, факты)
   -> llm.py (Ollama: факт -> живая фраза) - опционально
   -> tts.py (SAPI-голос) + overlay.py (окно-советы)
сборки и тайминги: builds.py <- OpenDota API (бесплатно, без ключа)
```
